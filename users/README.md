# Users

Προσθέτει εγγραφή, επιβεβαίωση email, σύνδεση, ανάκτηση κωδικού και προβολή λογαριασμού. Μπορεί να εγκατασταθεί απευθείας στον κορμό.

1. Από τη ρίζα του έργου τρέξε `npm run module:add -- users`.
2. Ρύθμισε τη βάση και το SMTP. Για τοπική ανάπτυξη τρέξε `npm run services:up`.
3. Τρέξε `npm run db:migrate` και `npm run dev`.
4. Άνοιξε το `/users`. Για τοπική επιβεβαίωση λογαριασμού χρησιμοποίησε το inbox του Mailpit.

Το `files/` αντιγράφεται στο έργο, το `schema.prisma` προσθέτει τα μοντέλα της λειτουργίας και το `module.json` δηλώνει την έκδοση και τις εξαρτήσεις. [Λεπτομέρειες για τον κώδικα και το API](files/src/modules/users/README.md)
