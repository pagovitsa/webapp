# Κοινή υποδομή server

Ο φάκελος [database](database/README.md) ανοίγει τη σύνδεση Prisma με MySQL. Το `env.ts` διαβάζει τις ρυθμίσεις περιβάλλοντος και ο φάκελος `email/` έχει τον κοινό SMTP connector. Ο κατάλογος ταυτοποίησης προστίθεται όταν εγκαθιστάς το Users.

Οι λειτουργίες χρησιμοποιούν την υποδομή μέσω του δικού τους server κώδικα. Τα components στον browser καλούν ένα action ή API για να ζητήσουν τη λειτουργία. Όρισε τις τιμές περιβάλλοντος από το [.env.example](../../.env.example).
