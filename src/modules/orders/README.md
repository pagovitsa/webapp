# orders

> Δοκιμαστικό module: δείχνει πού μπαίνει κάθε αρχείο. Αφαιρείται σε νέο project (`docs/new-project.md`).

## Σκοπός και ευθύνη

Δημιουργία, λίστα και αλλαγή κατάστασης παραγγελιών. Δεν διαχειρίζεται πελάτες, πληρωμές ή αποστολές.

## Δεδομένα που διαχειρίζεται

- `Order`: αριθμός, όνομα πελάτη (ελεύθερο κείμενο), ποσό, κατάσταση, ημερομηνία δημιουργίας. Μόνο αυτό το module αλλάζει την κατάσταση μιας παραγγελίας.

## Κανόνες domain

- Όνομα πελάτη: τουλάχιστον 2 χαρακτήρες (μετά από trim).
- Ποσό: ακέραιος σε λεπτά, > 0 και ≤ 100.000 €.
- Νέα παραγγελία ξεκινά ως `draft`.
- `confirm`: μόνο από `draft`.
- `cancel`: από οποιαδήποτε κατάσταση εκτός `cancelled`.

## Use cases

| Use case | Είδος | Περιγραφή |
|---|---|---|
| `create-order` | δημιουργία | Νέα πρόχειρη παραγγελία. |
| `list-orders` | ανάγνωση | Όλες, από τη νεότερη. |
| `change-order-status` | μεταβολή | Επιβεβαίωση ή ακύρωση. |

## Παραδείγματα συμπεριφοράς

| Είσοδος / κατάσταση | Αποτέλεσμα |
|---|---|
| πελάτης «Μαρία Π.», ποσό `49,90` | επιτυχία: `ORD-000N`, κατάσταση `draft` |
| ποσό `abc` | απόρριψη (schema): «Το ποσό πρέπει να είναι αριθμός, π.χ. 49,90.» |
| ποσό `0` | απόρριψη (domain): «Το ποσό πρέπει να είναι μεγαλύτερο από μηδέν.» |
| επιβεβαίωση `draft` | επιτυχία: `confirmed` |
| επιβεβαίωση `cancelled` | απόρριψη (domain): «Επιβεβαιώνονται μόνο πρόχειρες παραγγελίες.» |

## Επανάληψη έναντι παραβίασης κανόνα

| Action | Περίπτωση | Συμπεριφορά σήμερα |
|---|---|---|
| `createOrderAction` | παραβίαση κανόνα | Μήνυμα στη φόρμα. |
| `changeOrderStatusAction` | επανάληψη (π.χ. διπλό κλικ) | Χωρίς μήνυμα· η λίστα δείχνει την τρέχουσα κατάσταση. |
| `changeOrderStatusAction` | παραβίαση κανόνα | **Ίδια με την επανάληψη** — δεν ξεχωρίζουν. Γνωστή απόκλιση, αποδεκτή επειδή το module είναι δοκιμαστικό. |
| όλα | τεχνικό σφάλμα | Πετιέται προς τα πάνω. |
