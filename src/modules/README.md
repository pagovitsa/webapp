# Λειτουργίες ανά project

Κάθε φάκελος εδώ αντιστοιχεί σε μία λειτουργία. Ξεκίνα νέο module με `npm run module:new -- customers --page`. Για έτοιμη λειτουργία από τον κατάλογο χρησιμοποίησε `npm run module:add -- <όνομα>`. [Οδηγός δημιουργίας](../../docs/new-module.md) · [Εγκατάσταση έτοιμου module](../../scripts/README.md)

- `domain/` έχει τους καθαρούς επιχειρησιακούς κανόνες.
- `application/` έχει ενέργειες και περιγράφει τις εξαρτήσεις τους.
- `infrastructure/` υλοποιεί πρόσβαση σε βάση ή άλλες υπηρεσίες.
- `presentation/` έχει φόρμες, components και actions.
- `server.ts` είναι η δημόσια είσοδος για server κώδικα και `contracts.ts` έχει τους δημόσιους τύπους.

Η σελίδα εισάγει δημόσια components ή καλεί τη δημόσια είσοδο server. Ένα module που χρειάζεται άλλο module δηλώνει την εξάρτηση και χρησιμοποιεί τα δημόσια σημεία του.

[Παράδειγμα «Νέα αναφορά» με φόρμα και αποθήκευση](../../docs/new-module.md#παράδειγμα-για-αρχάριους-φόρμα-νέα-αναφορά)
