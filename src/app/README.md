# Σελίδες και routes

Το Next.js χρησιμοποιεί τους φακέλους εδώ για τις διευθύνσεις της εφαρμογής. Το `page.tsx` εμφανίζει την αρχική σελίδα, το `layout.tsx` ορίζει το κοινό περίβλημα και το `globals.css` περιέχει τα κοινά στυλ. Μια νέα σελίδα στο `customers/page.tsx` ανοίγει στο `/customers`. Ένα `api/customers/route.ts` εξυπηρετεί αιτήματα στο `/api/customers`.

Κράτα εδώ το σημείο εισόδου κάθε σελίδας. Βάλε φόρμες και συμπεριφορά της λειτουργίας στο [αντίστοιχο module](../modules/README.md). Για πρόσβαση σε δεδομένα από τη σελίδα ή το API χρησιμοποίησε τη δημόσια είσοδο server του module. Τα έτοιμα modules προσθέτουν τα δικά τους routes κατά την εγκατάσταση.
