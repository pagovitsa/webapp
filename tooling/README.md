# Τοπικές υπηρεσίες

Το `dev-services.mjs` ξεκινά MySQL και Mailpit μέσω Docker. Χρησιμοποίησέ το με `npm run services:up` από τη ρίζα του project. Δημιουργεί τοπικές ρυθμίσεις αν λείπουν. Το Playwright διαβάζει από τον ίδιο helper τις ρυθμίσεις για τη χωριστή δοκιμαστική βάση.

Ο helper χρησιμοποιεί σταθερά ονόματα και ports. Για παράλληλη εκκίνηση ανεξάρτητων έργων στον ίδιο Docker host, δες τις ρυθμίσεις που πρέπει να διαφέρουν στον [οδηγό νέου project](../docs/new-project.md#3-τοπική-βάση-και-email).
