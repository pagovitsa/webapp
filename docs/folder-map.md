# Ο χάρτης του Webapp Starter

Αν ανοίγεις το έργο για πρώτη φορά, ξεκίνα από το `webapp/README.md`. Αυτός ο χάρτης ακολουθεί τους φακέλους όπως εμφανίζονται στην Εξερεύνηση αρχείων.

## Μέσα στο `src/` γράφεις την εφαρμογή

| Φάκελος | Τι βάζεις εκεί | Γιατί |
|---|---|---|
| `src/app/` | Σελίδες, κοινή διάταξη και σημεία εισόδου του API. | Το Next.js χρησιμοποιεί τα ονόματα των φακέλων για να αντιστοιχίζει διευθύνσεις, όπως `/reports`, σε αρχεία. |
| `src/modules/` | Τους κανόνες, τις ενέργειες, τις φόρμες και την πρόσβαση στα δεδομένα κάθε λειτουργίας. | Κάθε λειτουργία έχει μία θέση και η σελίδα και το API μπορούν να καλούν την ίδια λογική. |
| `src/server/` | Την κοινή σύνδεση MySQL, τις ρυθμίσεις του server και την αποστολή email. | Όλες οι λειτουργίες χρησιμοποιούν την ίδια υποδομή. Οι κωδικοί της βάσης μένουν στον server. |
| `src/shared/` | Κοινά κουμπιά, πεδία και γενικές βοηθητικές συναρτήσεις. | Διαφορετικές λειτουργίες μπορούν να τα χρησιμοποιούν χωρίς να εξαρτώνται μεταξύ τους. |

## Δίπλα στο `src/` βρίσκονται η βάση, τα εργαλεία και οι οδηγίες

| Φάκελος ή αρχείο | Τι βάζεις εκεί και πότε το ανοίγεις |
|---|---|
| `prisma/` | Τα μοντέλα των πινάκων στο `schema.prisma` και τις καταγεγραμμένες αλλαγές στη δομή τους στο `migrations/`. |
| `public/` | Δημόσια αρχεία, όπως το λογότυπο ή τα εικονίδια της εφαρμογής. |
| `scripts/` | Τα προγράμματα που δημιουργούν σκελετούς και εγκαθιστούν έτοιμα modules. |
| `templates/` | Τα πρότυπα αρχείων που αντιγράφονται όταν δημιουργείς καινούργιο module. |
| `docker/` και `tooling/` | Ρυθμίσεις αρχικοποίησης MySQL στο πρώτο και εργαλεία εκκίνησης των τοπικών υπηρεσιών στο δεύτερο. |
| `tests/` και `.github/` | Δοκιμές του έργου στο πρώτο και αυτοματοποιημένοι έλεγχοι του GitHub στο δεύτερο. |
| `docs/` και `README.md` | Αναλυτικοί οδηγοί στο πρώτο και εκκίνηση, εντολές και σύνδεσμοι στο δεύτερο. |
| `package.json` και `.env.example` | Εντολές και βιβλιοθήκες του έργου στο πρώτο και υπόδειγμα των ρυθμίσεων στο δεύτερο. |

Ο διπλανός φάκελος `webapp-modules/` περιέχει τις έτοιμες λειτουργίες. Κάθε έργο επιλέγει ποιες θα εγκαταστήσει. Ο κατάλογος δίνει τον κώδικα στον εγκαταστάτη, ο οποίος τοποθετεί τα αρχεία στα αντίστοιχα σημεία του `webapp/`.

**Παράδειγμα.** Αν προσθέτεις Αναφορές, βάζεις τη σελίδα στο `src/app/reports/page.tsx`, τους κανόνες στο `src/modules/reports/` και τυχόν αλλαγές πινάκων στο `prisma/`. Αν η φόρμα των αναφορών χρησιμοποιεί ένα κοινό κουμπί, μπορεί να το εισαγάγει από το `src/shared/`. Όλη η ομάδα ακολουθεί την ίδια διαδρομή σε κάθε νέο έργο.
