# Εργαλεία για modules

| Εντολή | Χρήση |
|---|---|
| `npm run module:new -- customers --page` | Δημιουργεί σκελετό για νέα λειτουργία. |
| `npm run module:list` | Δείχνει τα έτοιμα modules, εκδόσεις και απαιτούμενες εξαρτήσεις. |
| `npm run module:add -- users` | Προσθέτει το Users στο συγκεκριμένο project. |
| `npm run db:migrate` | Εφαρμόζει τις νέες migrations στη βάση του συγκεκριμένου project. |

Το `new-module.mjs` χρησιμοποιεί τους σκελετούς στο `templates/`. Το `install-module.mjs` διαβάζει τα έτοιμα modules από τον διπλανό φάκελο `webapp-modules` ή από το `WEBAPP_MODULES_DIR`. Πριν γράψει αρχεία, ελέγχει εξαρτήσεις και συγκρούσεις. Το `modules.lock.json` καταγράφει ποια έκδοση έχει εγκατασταθεί.

Αν ο installer αναφέρει σύγκρουση, έλεγξε το αρχείο που κατονομάζει και τις απαιτήσεις του module. Κράτησε την εγκατάσταση σε χωριστό branch ώστε να μπορείς να ελέγξεις τις αλλαγές πριν τις ενσωματώσεις.
